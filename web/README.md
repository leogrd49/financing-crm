# Formulaire web — Financing CRM

Formulaire Next.js qui crée un dossier de financement dans Salesforce via l'API REST Apex,
authentifié en OAuth 2.0 Client Credentials. Voir le [README principal](../README.md).

```bash
cp .env.example .env.local   # Consumer Key / Secret de l'External Client App
npm install
npm run dev
```
